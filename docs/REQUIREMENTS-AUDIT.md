# MANLYFY — requirements audit

17 October 2026 · Release 1.6.1. This review combines the recovered conversation requirements, the existing detailed audit, the latest requests and the current source. The latest user instruction controls when a preference changed. Source implementation, automated behavior and physical-device verification are separate.

The latest pass corrected small detector input, single-face imported videos and per-face designs being overwritten. It adds an owner master link, fast-motion reacquisition, persistent individual face styles, frame-by-frame video processing, original-resolution exports up to 4K, and a three-second logo/name/tagline ending. The private master token is not in this repository. See [current validation](TESTING.md).
